# 本地离线演示说明

这份说明对应当前竞赛展示版本。它只覆盖网站展示页和 Streamlit 交互页，不启动科研计算、训练任务或 Paper1/Paper2 控制面。

## 推荐演示路线

1. 打开展示页 `competition/website展示页_校赛副本/index.html`，从首页进入设计系统。
2. 在交互页侧栏点击“加载已审核示例”。页面会载入一个已存在于审核参考库中的精确几何：TiO2/SiO2/air、TM、0°、D/H/P=140/281/407 nm。
3. 在“预览”页确认当前路线颜色和结构参数，展开“高保真参考对照”，查看精确命中记录、参考光谱、逐波长差异、RMSE 和 Delta E2000。
4. 切换到“逆设计”，输入目标颜色并运行当前可用的推荐搜索方法；旁白使用“候选筛选结果”，不说“全局最优”。
5. 回到“光谱”查看反射光谱和 CIE 信息，在“映射”或“图案”页展示扩展能力，最后下载 JSON/CSV/PNG 结果。

## Windows 启动

在项目根目录 PowerShell 执行：

```powershell
python -m pip install -r requirements-web.txt
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8512
```

浏览器打开 `http://127.0.0.1:8512`。若 8512 已被占用，改用其他本地端口，并在录屏脚本中保持一致。

## Linux/macOS 启动

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-web.txt
python -m streamlit run app.py --server.address 127.0.0.1 --server.port 8512
```

核心演示不需要大模型密钥；`ENABLE_LLM_FEATURES` 当前关闭。不要为了录屏临时打开外部 API。

## 发布前检查

```powershell
python scripts/verify_ui_release.py --root . --pretty
python scripts/make_ui_release_manifest.py --root . --output dist/ui-release-manifest.json --pretty
python scripts/build_web_deployment_bundle.py
python scripts/smoke_web_bundle.py dist/ai_metasurface_web_bundle_20261011_v5.zip --port 8514
```

检查结果必须为 `status=pass`、ZIP `testzip=None`、Streamlit health 为 HTTP 200。发布包只包含竞赛运行时、网站资源和已审核参考资产，不包含科研控制面、训练集、holdout、active pool 或长时间 RCWA 任务。

## 现场边界

- 参考库只接受 JSONL 中存在的精确整数 D/H/P，不做最近邻、插值或训练。
- 参考颜色和光谱是审核参考资产；当前代理/解析路线与参考的差异应如实展示。
- `nG=151`、21,088 条记录和守恒检查是该参考版本的资产信息，不是全域收敛或模型准确率证明。
- 若公网服务不可用，优先使用本地展示页和本地交互页，不临时连接科研控制面。
