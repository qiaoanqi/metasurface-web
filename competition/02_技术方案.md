# 技术方案（校赛版主稿）

## 1. 项目概述

本系统是面向超表面结构色验证场景的 AI 算法与软件展示系统。它把目标颜色、模型候选、结构参数、光谱和色度信息放在同一条可交互链路中，帮助用户完成快速探索、边界判断和方案导出。

本方案以算法创新赛 · AI+软件创新为竞赛主线，网站式展示页作为首屏叙事和产品化入口，交互应用作为演示载体。不把尚未完成的高保真科研计算包装成产品功能。系统输出的模型预测、解析近似和历史科研结果均在界面中区分来源，并保留适用边界。

## 2. 用户痛点

传统结构色设计通常需要在材料、几何尺寸、周期、入射条件之间反复试错。高保真仿真单次成本较高，结果还需要经过色度学转换才能判断是否接近目标颜色。教学和早期方案设计阶段缺少一个能快速交互、可视化和导出的统一工具。

## 3. 解决方案

用户在界面中选择结构路线、材料、衬底、偏振和入射角，并输入或选择目标颜色。系统根据当前上下文检查模型适用域，然后调用可用的代理模型、解析/半解析模型或 FP-TMM 路线。系统返回候选结构参数，并同步展示：

- 当前模型路线下的颜色预览与 RGB/HEX 显示信息；
- 反射光谱与 CIE 1931 色度图；
- 目标色逆设计候选及 ΔE00；
- 参数灵敏度和入射角扫描结果；
- 图案到结构参数的映射结果；
- CSV、JSON、PNG 等导出文件。

## 4. 系统架构

```text
用户输入
  ├─ 结构类型、材料、衬底、偏振、入射角
  ├─ 几何参数或目标颜色
  └─ 图案上传
        ↓
上下文与适用域检查
        ↓
模型路由层
  ├─ RCWA 训练代理模型
  ├─ Lorentz/Fano 解析或半解析路线
  ├─ FP-TMM 腔体路线
  └─ 角谱/NA 远场后处理
        ↓
光谱与色度学计算
        ↓
可视化、逆设计候选、图案映射
        ↓
结果导出与来源说明
```

## 5. AI 与物理模型协同

机器学习代理模型用于快速预测结构参数对应的光谱或颜色，并为目标色搜索提供候选。物理近似路线用于补充模型不可用的结构场景，FP-TMM 用于薄膜腔体路线。系统不会把不同模型的结果混成一个无来源的数值，而是保留 route、model version 和 boundary 信息。算法层重点展示代理模型的适用域、候选排序和预测与物理表达之间的差异，避免把一次预测包装成“全局最优”。

## 6. 核心功能

### 正向设计

输入纳米柱直径 D、高度 H、周期 P 等参数，得到颜色预览、光谱和色度信息。

### 目标色逆设计

选择目标色后，系统在当前结构、材料、衬底和模型域内搜索候选结构，并提供候选排序与色差指标。候选结果仍需在同一物理口径下进一步复核。

### 图案映射

上传图像后，系统将图像像素映射到单柱解析近似颜色库，输出结构参数阵列、映射图和 metadata。

### 分析与导出

系统提供 CIE 1931 色度图、入射角扫描、参数灵敏度、光谱 CSV、当前结果 JSON 和色板 PNG 导出。颜色与色差数值属于当前模型路线内的候选表达，不作为未经高保真仿真或实验复核的绝对物理真值。

## 7. 当前可展示的工程证据

- Streamlit 应用可在本地启动，健康检查返回正常；
- 关键 UI、交互、模型资源、图案和色度学合同测试已通过；
- 当前发布门禁、关键 UI 合同和本地 smoke 检查均通过；具体结果以提交包中的测试日志为准；
- 主程序和核心 UI 模块可通过 Python 编译检查；
- 系统具备本地离线运行路径，不依赖外部大模型才能完成核心演示。
- 已发现并记录历史圆形 RCWA 数据路线的物理口径风险：旧代理颜色可被软件链路稳定复现，但不能直接替代空气背景、能量守恒的高保真复核；参赛演示以算法流程、适用域和复核边界为主。

## 8. 创新点

1. 将目标色逆设计、光谱分析、图案映射和结果导出放到同一软件流程中。
2. 在用户界面中显式标注模型来源、版本和适用边界，降低“模型预测等于实验结果”的误解。
3. 将 AI 候选搜索与结构色物理分析结合，支持从单点颜色设计扩展到图案级参数映射。
4. 将代理模型的边界和优化偏差纳入展示流程，以“可解释筛选”替代只报一个最优参数。

## 9. 应用场景

- 超表面显示和结构色器件的早期方案设计；
- 光学标识、防伪和微纳图案设计；
- 光学、材料和微纳加工课程的实验教学；
- 研究人员进行材料与几何参数的快速筛选。

## 10. 当前边界与后续计划

当前系统主要用于快速设计、可视化和候选筛选。代理预测不等同于直接 RCWA 或实验测量，部分结构路线的模型域和证据范围不同；当前不对具体 HEX 色值、绝对色差或实验颜色作无条件承诺。后续计划包括：为圆形 D/H/P 路线重建空气背景数据、完成独立模型与闭环复核，再绑定统一版本的效果测试、用户试用、可制造约束和实验复核接口。
