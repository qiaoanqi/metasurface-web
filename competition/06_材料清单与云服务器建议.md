## 云服务器推荐配置

### 首选：稳定展示型配置

- 4 vCPU
- 16 GB RAM
- 100 GB SSD
- 5 Mbps 以上公网带宽，建议 10 Mbps
- Ubuntu 22.04 LTS 或同等长期支持版本
- 1 个固定公网 IPv4
- 开放 80/443，应用端口仅本机监听并由 Nginx 反向代理

这套配置足够支撑 Nginx 静态网站、Streamlit 在线展示、ONNX Runtime 推理和少量并发评审访问。校赛展示不需要 GPU。

### 可接受最低配置

- 2 vCPU
- 8 GB RAM
- 80 GB SSD
- 5 Mbps 公网带宽
- Ubuntu 22.04 LTS

只适合少量评委访问和单人演示，不建议作为答辩当天的唯一配置。

### 推荐升级：评审访问较多或需要并行演示

- 4 vCPU
- 16 GB RAM
- 100 GB SSD
- 10 Mbps 公网带宽
- 进程管理使用 systemd 或 Docker Compose
- Nginx 负责 HTTPS、静态页和反向代理

### 不建议为了校赛购买

- GPU 实例
- 高并发数据库
- 大规模分布式计算节点
- 过高带宽套餐

本系统的校赛主线是预加载模型后的交互式展示，不是在线运行长时间 RCWA 或训练任务。

## 部署注意事项

- 预先把模型文件和 Python 依赖打包，避免现场下载。
- 在线展示页面关闭不必要的外部 API 功能。
- 设定最大上传图片尺寸和请求超时。
- 保留一个本地离线启动包作为公网故障时的备份。
- 在服务器上只运行竞赛展示版本，不部署科研控制面和受保护数据池。
